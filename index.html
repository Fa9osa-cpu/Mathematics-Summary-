جذع مشترك علوم وتكنولوجيا

1. الأعداد والحساب

  • المجموعات: N ⊂ Z ⊂ D ⊂ Q ⊂ R
  • PGCD: العوامل المشتركة بأصغر أس.
  • PPCM: العوامل المشتركة والغير مشتركة بأكبر أس.
  • القيمة المطلقة والمسافة:
|x - a| ≤ r ⇔ a - r ≤ x ≤ a + r

2. عموميات على الدوال

  • الدالة الزوجية: f(-x) = f(x) (متناظرة بالنسبة لمحيور التراتيب)
  • الدالة الفردية: f(-x) = -f(x) (متناظرة بالنسبة للمبدأ O)
  • اتجاه التغير: x1 < x2
    ← متزايدة إذا حافظت على الترتيب f(x1) < f(x2)
    ← متناقصة إذا عكست الترتيب f(x1) > f(x2)

3. الدوال المرجعية

الدالة العبارة الشفعية المنحنى
المربع f(x) = x² زوجية قطع مكافئ
المقلوب f(x) = 1/x فردية قطع زائد
الجذر f(x) = √x لا شفعية منحنى يتزايد

4. الحساب الشعاعي والهندسة

  • مركبات الشعاع: AB(xB - xA , yB - yA)
  • منتصف قطعة: I( (xA+xB)/2 , (yA+yB)/2 )
  • شرط الارتباط الخطي (u(x,y) و v(x',y')):
x · y' - x' · y = 0
